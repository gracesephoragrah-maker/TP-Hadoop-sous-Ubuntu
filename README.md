# TP-Hadoop-sous-Ubuntu
TP de Big Data : dans ce TP, nous avons installé un cluster Hadoop pseudo-distribué sous Ubuntu via Multipass/Hyper-V sur Windows. Nous avons ensuite manipulé HDFS et programmé des traitements MapReduce en Python comme: WordCount, le chiffre d’affaires par ville, la température maximale, la moyenne et combiner.
